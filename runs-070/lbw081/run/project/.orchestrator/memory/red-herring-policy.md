If you establish a character's ability or label someone the 'obvious suspect' as a red herring, record that intent in the index immediately. Do not rely on implied later payoffs. If the payoff is deferred, mark the detail as 'intentional misdirection' so the whole-story pass can see it as a device rather than a forgotten promise. This avoids later revision pressure and prevents the detail being treated as an unpaid promise.
