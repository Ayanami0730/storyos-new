Lesson (generalized): When a scene establishes an intimate or plot-bearing promise (private vows, escape plans, sealed notes), record alongside it an explicit expected payoff (scene id or chapter) or else mark the promise as intentionally ambiguous/breakable. Rationale: the whole-story pass commonly finds ‘intimate promises’ left unpaid; either payoffs must be planned across the span or the text must foreshadow their failure so the absence reads as design, not neglect. Procedure to adopt next time: 1) Whenever a scene creates a promise that will be tracked, include an 'expected_payoff' field (scene id or 'deferred') and an 'alternative_outcome' flag (true/false). 2) If alternative_outcome=true, add at least one foreshadowing beat within two subsequent scenes. 3) Verify these fields in the planner’s pre-commit checklist so a promise does not land on the ledger without a traceable disposition.
