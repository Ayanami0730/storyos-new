When folding the first scene, be strict: record only what is prose-supported. Put sensory and quoted lines into state entries with exact quotes. Do not convert descriptive one-off phrases into identity attributes; instead use events. Record object containment as state (holds) if it is the current situation. Keep the promise registration for any explicit request quote; mark promises paid off only when the scene both registers and fulfills the explicit ask. Note: do not create scene text files in the index — that is orchestrator's task; index holds metadata only.
