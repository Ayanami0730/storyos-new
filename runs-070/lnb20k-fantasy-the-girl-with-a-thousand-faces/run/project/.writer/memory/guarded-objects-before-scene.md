When a later relation file assigns guardianship or ownership starting at a later scene, do not describe the character as holding or guarding that object earlier. If you need the object in an earlier scene, describe it as a personal packet, copy, or folding notes and record that phrasing. This avoids contradictions with relation 'fromScene' markers; add a one-line metadata note in repaired drafts explaining the change.
