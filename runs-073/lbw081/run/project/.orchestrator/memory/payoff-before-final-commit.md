Always resolve established promises (transcriptions, ledgers) or explicitly mark them as intentionally unresolved in the final scene. If left unpaid, record where the evidence would be and why it remains pending (lab backlog, custody). In practice: either (A) pay off in the last scene with a compact, non-contradictory beat (e.g., police desk note, a lab tech reads the cipher aloud, ledger photocopy shown) or (B) move the payoff into a short epilogue/police report so the main narrative arc stays intact. This avoids the ‘abandoned promise’ defect on the whole-story pass.
