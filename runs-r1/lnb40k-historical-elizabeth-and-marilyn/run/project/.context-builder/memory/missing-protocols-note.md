In early builds we lack a world/protocols.yaml and explicit relations files for the Queen with senior staff; this causes many scene intents to rely on the writer inventing staff conduct. Recommend adding minimal protocol entries (who may accompany the sovereign on private walks, typical staff shadowing practices, and household timing anchors) to reduce writer guesswork.
