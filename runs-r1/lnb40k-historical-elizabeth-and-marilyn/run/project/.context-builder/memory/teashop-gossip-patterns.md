Windsor teashop gossip should read as polite curiosity edged with deferential restraint: people notice and note, often phrasing curiosity as worried praise or puzzled admiration (e.g. 'Did you see—?','Of course she’s lovely, but—','Well, they’ll have it all arranged'). Record suggested phrasings for writers to reuse, but do not assert them as world facts. Based on absence of committed exemplars in the index and the project's need to avoid inventing core facts silently.
