When committing a scene, read the prose and the proposed delta, decide what to record across identity, state, beliefs, relations, events, rhythm and promises, and then issue all writes in a single batch. Do not put story facts in memory. If a tentative lesson mentions a scene, rephrase it as a general procedure.
