If a writer declares a staged state delta file but the file is missing at commit time: 1) Do not invent values; use verbatim prose quotes from the scene to backfill the declared claims into the index, preserving the writer's declared attribute names and values. 2) Record provenance as the scene id. 3) Record a memory note so the writing team knows to stage deltas. 4) Note in commit message that delta was missing and was backfilled. 5) Do not put story facts into the index-manager's memory; this is a procedural note only.
