When indexing a scene that includes photographs or recordings, always record the exact filenames and how they were obtained (time, location, brief method) as identity/state or event evidence. Do not convert inferred provenance into an identity attribute — treat provenance claims as beliefs or relation phases (suspected linkages) unless the prose explicitly states ownership/origin. Record comparisons (e.g., handwriting similarity) as a relation phase, and physical matches (stain looks like tea) as events plus beliefs, not as established provenance.
