Don't change established character profile phrases when summarising actions. If a character's habit was recorded in the index (e.g., 'timestamps and records events in notebook'), mirror that exact wording in scene prose or explicitly refer to the earlier entry (quote it) rather than rephrasing. Rationale: small wording changes become continuity errors; record exact prior phrasing when referencing it.
