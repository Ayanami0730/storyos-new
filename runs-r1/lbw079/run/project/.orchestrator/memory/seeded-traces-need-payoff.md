What happened: two physical traces (a red-brown smear on the locket and a stopped hallway clock time) were introduced early and never resolved by committed scenes. What I would do next time: when adding a concrete, physical clue in an opening scene, also schedule its explicit payoff in a later scene (or reserve an epilogue) so the whole-story pass does not have to choose between risky rewrites and leaving promises unpaid. Practical rule: every new object or mark seeded → record its intended payoff scene and the minimal physical test that will satisfy the reader (e.g., 'smear = tannin; payoff: color match + photograph' or 'clock time = event timestamp; payoff: diary entry or witness line').
