When you set up a demonstrable promise (camera, physical match, labelled monogram), finish it explicitly on the page with either forensic proof or an on-the-record admission. In this run two promises were left unpaid: the handkerchief monogram was indexed as unreadable and never matched on the page, and the daylight demonstration wording promised camera/notebook evidence that never landed as indexed fact. Next time, either (a) include the physical proof in the same scene, or (b) plan an explicit, short epilogue scene that records the admission or lab result as scene-level provenance. This avoids a broken promise that later scenes were written against.
